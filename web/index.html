Sobre esta edición

Es la traducción al español de Introduction to Python Programming, un libro de texto abierto de OpenStax. Se respetó el contenido del original, se corrigieron las respuestas de las preguntas de repaso y se añadieron 90 ejercicios propios con pruebas automáticas, pistas y soluciones.

Puedes copiarlo, adaptarlo y compartirlo sin fines comerciales, citando la fuente y con la misma licencia. El código está en GitHub; las erratas se reportan allí.
